# HEX16 Comparison Tool

A modern, tech-inspired web application for comparing HEX16 data and calculating file checksums with glassmorphism design.

## Features

### 🎯 HEX Data Comparison
- Side-by-side HEX data input
- Color-coded difference highlighting
- Detailed comparison statistics
- Duplicate HEX value detection

### 📁 File Checksum Comparison
- Support for multiple hash algorithms:
  - MD5
  - SHA-1
  - SHA-256
  - SHA-512
- Compare checksums between two files
- Visual match/mismatch indicators
- Single file checksum calculation

### 🌐 Language Support
- English (default)
- Chinese
- One-click language switching

### 🎨 Modern Design
- Glassmorphism effects with backdrop blur
- Tech-inspired dark gradient background
- Neon accent colors
- Smooth animations and transitions
- Fully responsive layout

## Quick Start

1. Clone or download this repository
2. Open `index.html` in a modern web browser
3. Start comparing HEX data or calculating file checksums

## Usage

### Comparing HEX Data
1. Enter HEX data into both input fields
2. Click the "Compare" button
3. View the differences highlighted in the results section
4. Check duplicate values using the "Check Duplicates" button

### Calculating File Checksums
1. Select one or two files using the file inputs
2. Click "Calculate Checksums" to generate checksums
3. For two files, click "Compare Checksums" to see the comparison
4. Use "Clear Files" to reset selections

### Switching Language
- Click the "中文 / English" button in the header to toggle between languages
